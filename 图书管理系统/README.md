# 图书管理系统（Library Management System）

基于 **Python + Tkinter + SQLite** 的桌面图书管理软件，面向校园图书馆场景，覆盖图书检索、借阅、归还、续借、图书与读者管理、统计报表等完整业务，可在 x86-64 Windows 环境直接运行，并提供 PyInstaller 打包的单文件 `.exe`。

## 一、功能特性

### 管理员（控制台）
- **图书管理**：图书新增、修改、删除，按书名/作者/ISBN 关键字与分类查询；
- **读者管理**：新增读者、启用/禁用账号、重置口令；
- **借阅办理**：选择读者与图书办理借出，实时查看全部在借记录；
- **归还 / 续借**：按读者筛选在借记录，办理归还（自动计算逾期罚款）与续借；
- **统计报表**：图书种类/册数、读者数、当前借出、逾期数量汇总，分类馆藏柱状图、图书借阅热度；
- **操作日志**：登录、借阅、归还、续借及管理操作全程留痕。

### 读者（读者中心）
- **图书检索 / 借阅**：多条件检索馆藏并自助借阅；
- **我的借阅**：查看在借图书与应还日期、逾期状态，自助续借，查看历史记录与罚款；
- **个人信息**：查看读者信息、修改登录口令。

## 二、业务规则

| 项目 | 规则 |
|---|---|
| 借期 | 30 天 |
| 最大在借数量 | 每人 5 本 |
| 续借 | 每本可续借 1 次，延长 30 天；已逾期不可续借 |
| 逾期罚款 | 0.5 元 / 天，归还时自动计算 |
| 借阅前置校验 | 图书有在馆库存、在借未超上限、无逾期未还图书 |
| 口令安全 | PBKDF2-SHA256 加盐哈希存储，不明文保存 |

## 三、默认账号（首次运行自动创建）

| 角色 | 用户名 | 口令 |
|---|---|---|
| 管理员 | `admin` | `admin123` |
| 读者 | `reader` | `reader123` |

读者也可在登录界面点击“读者自助注册”创建新账号。**正式使用请及时修改默认口令。**

## 四、运行方式

### 方式 1：直接运行 exe（无需 Python 环境）
双击 `LibrarySystem.exe`（位于 `dist/` 目录）即可使用。数据库文件 `library_data.db` 会在 exe 同目录自动创建，拷贝整个文件夹即可迁移数据。

### 方式 2：从源码运行
需要 Python 3.10 及以上（Windows 自带 tkinter）：

```
python main.py
```

### 打包 exe
```
python -m pip install pyinstaller
build.bat
```
产物为 `dist/LibrarySystem.exe`（单文件、窗口模式、带应用图标）。

## 五、项目结构

```
图书管理系统/
├── main.py                  # 程序入口
├── library/
│   ├── database.py          # SQLite 建表、连接与初始数据
│   ├── auth.py              # 口令加盐哈希与校验
│   ├── services.py          # 全部业务逻辑（借阅/归还/续借/统计等）
│   ├── widgets.py           # 主题样式与通用对话框
│   ├── login_window.py      # 登录与注册界面
│   ├── admin_window.py      # 管理员控制台（6 个标签页）
│   └── reader_window.py     # 读者中心（3 个标签页）
├── app.ico                  # 应用图标
├── build.bat                # exe 打包脚本
├── requirements.txt
└── README.md
```

## 六、技术说明
- 界面：Tkinter / ttk（Python 标准库，零第三方运行时依赖）；
- 数据库：SQLite（单文件、免部署）；
- 安全：PBKDF2-SHA256（10 万次迭代 + 随机盐）；
- 打包：PyInstaller `--onefile --windowed`，目标平台 x86-64 Windows。
